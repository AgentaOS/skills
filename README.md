# AgentaOS Skills

Agent skills for [AgentaOS](https://agentaos.ai) — the financial OS for the agent economy.

## Available Skills

| Skill | Description | Install |
|-------|-------------|---------|
| [agenta](agenta/) | Accept payments and manage agent wallets via the AgentaOS CLI | `npx skills add AgentaOS/skills@agenta` |

## Install

```bash
npx skills add AgentaOS/skills@agenta
```
